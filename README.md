\# 湛箴面板 ZhanZhen Panel



> 本地優先的跨端智能文件工作台：讓審計、會計、稅務與專業文字工作者，可以在一個美觀、可編輯、可持久保存的面板中完成文件閱讀、編輯、分析與 AI 協作。



\## 一句話定位



湛箴面板不是「只能預覽文件的 AI 側邊欄」。



它是一個以本地文件為核心的智能工作台：使用者可以打開、編輯、保存和再次打開 Word、Excel、PDF 與 Markdown 文件；右側 AI 助手可以理解文件內容、協助分析、生成報告草稿、整理資料與提供審計工作建議。



\## 要解決的問題



目前很多 AI 文件插件只能做到：



\- 預覽 Office 文件

\- 讀取文件後回答問題

\- 臨時生成內容

\- 關閉後無法可靠保存修改



但審計、會計、稅務及企業服務工作真正需要的是：



\- 本地文件可打開、可編輯、可保存、可再次編輯

\- Word、Excel、PDF、Markdown 放在同一個工作台

\- 左側文件與專案導航，中間專業工作區，右側 AI 協作面板

\- 用戶可以拖拽、調整、組合自己的工作區塊

\- AI 不只模仿表面句子，而是理解使用者既有報告的論證結構、分析習慣、專業術語與寫作思路

\- 支援中文、英文及未來更多語言

\- 可作為湛箴審計風險平台的文件工作台與報告輸出入口



\## 核心能力



\### 1. 本地優先文件工作台



\- 建立、打開、編輯與保存本地文件

\- 支援 Markdown、TXT、DOCX、XLSX、PDF

\- 支援最近開啟文件、專案資料夾與本地自動保存

\- 不把使用者的真實客戶資料預設上傳到雲端



\### 2. 可編輯 Docs / Sheets 面板



\- 類 Obsidian 的本地檔案留存能力

\- 類 Proton Docs 的乾淨、克制、專業美學

\- 文件、表格、圖片、清單與 AI 生成內容皆可作為可調整的工作區塊

\- 支援區塊拖拽、重新排序與多欄工作區



\### 3. 湛箴 AI 助手



\- 在右側面板與使用者協作

\- 分析本地文件、Excel 表格與審計資料

\- 根據規則、數據與文件內容給出可追溯建議

\- 生成報告初稿、圖表說明、審計備忘與問題清單

\- 與湛箴的審計規則引擎、OCR 和證據哈希鏈逐步對接



\### 4. 讀書 Skill × 女媧 Skill



本項目最重要的 AI 能力不是普通「改寫」，而是建立使用者的 \*\*思路画像（Writing DNA）\*\*。



```text

歷史文章 / 報告 / 底稿

&#x20;       ↓

讀書 Skill：理解作者如何組織結構、如何論證、如何選擇證據

&#x20;       ↓

思路画像：論證鏈、風險披露習慣、術語表、句式與數字格式

&#x20;       ↓

女媧 Skill：先依照思路生成大綱，再由使用者確認後分段創作

&#x20;       ↓

可編輯、可保存、可追溯的專業文檔

```



系統必須做到「先理解思路，再開始寫作」：



\- 先輸出報告大綱，不直接生成整篇正文

\- 使用者確認或修改大綱後，才逐段生成

\- 使用者每次修改都可以回流為新的學習材料

\- 目標是讓 AI 越用越理解一個作者、一個團隊或一間事務所的寫作邏輯



\## 三端產品形態



| 平台 | 優先級 | 說明 |

|---|---:|---|

| Web 網頁版 | P0 | 最優先，瀏覽器打開即可使用 |

| Windows 桌面版 | P1 | 打包為可安裝或單文件 EXE，適合事務所本地辦公 |

| Android 移動版 | P2 | 打包 APK，適合文件查看、批註、任務處理與 AI 問答 |



\## 技術方向



\- 前端：Vue 3 + TypeScript + Vite

\- UI：Tailwind CSS + 自建湛箴設計系統

\- 編輯器：TipTap / ProseMirror

\- 跨端封裝：Tauri 2

\- 本地資料：SQLite + 本地檔案系統

\- 文件處理：SheetJS、docx、PDF.js

\- AI：DeepSeek / 通義千問 / 可選本地 Ollama

\- 多語言：vue-i18n

\- 字體：思源黑體、思源宋體、Inter、Noto 系列

\- 圖標：Lucide Icons



\## 設計方向



介面以「湛箴」品牌為核心：



\- 紫藍色、冰川藍、霧白為主色

\- 山水、可信任、智慧審計的品牌意象

\- 左側導航 + 中央工作區 + 右側 AI 協作欄

\- 高留白、柔和陰影、半透明玻璃卡片

\- 專業、平靜、可長時間使用，而非花哨的 AI 玩具

\## 與其他湛箴倉庫的關係



| 倉庫 | 職責 |

|---|---|

| `zhanzhen` | 中小企業審計風險平台 v1 框架：規則引擎、本地運行、證據哈希鏈 |

| `zhanzhen-mvp` | DSH 插件 MVP：本地 Docs / Sheets 編輯與保存驗證 |

| `zhanzhen-panel` | 跨端智能文件工作台：Web、Windows、Android，以及 AI 文件協作 |

| `Yamic` | 個人知識庫與湛箴工作流、視覺系統的原始設計資料 |



本倉庫專注於「文件工作台與專業寫作協作」，不直接替代風險規則引擎；未來透過明確的 JSON / API 契約接收湛箴的風險結論，並將其轉化為可編輯、可審核的專業報告。



\## 隱私原則



\- 使用者文件預設保留在本機

\- 真實客戶資料、原始審計底稿與敏感財務資料不可提交到 GitHub

\- 倉庫中僅使用脫敏範例資料

\- 任何雲端 AI 呼叫必須讓使用者明確知情與同意

\- 未來本地模型模式應作為敏感資料場景的優先選項



\## 開發狀態
