## 交互行為規格

### 1. 分頁切換（我的倉庫 / 我的 Star）

| 動作 | 行為 |
|---|---|
| 點擊「我的倉庫」標籤 | 下方內容區域切換為 59 倉庫卡片牆，URL 變為 `gallery.html?view=repos` |
| 點擊「我的 Star」標籤 | 下方內容區域切換為 42 Star 卡片牆，URL 變為 `gallery.html?view=starred` |
| 切換時 | 不重新加載頁面，使用 JavaScript 無縫切換（保持篩選器狀態） |

### 2. 分類摺疊/展開

| 動作 | 行為 |
|---|---|
| 點擊分類標題（如 `▼ AI-AGENT (10)`） | 該分類下的卡片牆展開/收合 |
| 收合時 | 標題前圖示變為 `▶`，卡片隱藏，只顯示分類名稱 + 數量 |
| 展開時 | 標題前圖示變為 `▼`，卡片顯示 |
| 多個分類 | 各自維護獨立摺疊狀態（AI-AGENT 展開時，PLUGIN 可以是收合的） |
| 記憶狀態 | 使用 localStorage 記住用戶的摺疊偏好，下次加載頁面時恢復 |

### 3. 篩選器

| 篩選維度 | 選項 |
|---|---|
| 語言 | 全部 / HTML / Python / JavaScript / TypeScript / Rust / ... |
| 評分 | 全部 / A 級 (綠色) / B 級 (藍色) / C 級 (黃色) / D 級 (橙色) / E 級 (紅色) |
| 主定位 | 全部 / AI-AGENT / PLUGIN-SDK-TEMPLATE / DEVICE-SYSTEM-SETUP / ... |

篩選邏輯：AND 關係（語言=Python AND 評分=A 級 AND 主定位=AI-AGENT）

### 4. 卡片顏色（FinalSPI 評級）

| 評級 | FinalSPI 範圍 | 卡片邊框顏色 | 背景色 |
|---|---|---|---|
| A 級 | >= 60 | `#22c55e` (綠色) | `#f0fdf4` |
| B 級 | 40-59 | `#3b82f6` (藍色) | `#eff6ff` |
| C 級 | 20-39 | `#eab308` (黃色) | `#fefce8` |
| D 級 | 0-19 | `#f97316` (橙色) | `#fff7ed` |
| E 級 | < 0 | `#ef4444` (紅色) | `#fef2f2` |

## 視覺風格參考（archify）

用戶提到「綠色類似多領我很喜歡」——推測是喜歡 archify 的綠色主題。

建議配色方案：

| 元素 | 顏色 |
|---|---|
| 主色調 | `#22c55e` (綠色，Tailwind `green-500`) |
| 背景色 | `#ffffff` (白色) |
| 卡片背景 | `#f9fafb` (淺灰，Tailwind `gray-50`) |
| 文字顏色 | `#111827` (深灰，Tailwind `gray-900`) |
| 邊框顏色 | `#e5e7eb` (淺灰，Tailwind `gray-200`) |

## 響應式設計

| 螢幕寬度 | 每行卡片數 |
|---|---|
| >= 1280px (桌面) | 4 張卡片 |
| >= 768px (平板) | 2 張卡片 |
| < 768px (手機) | 1 張卡片 |

## 實現技術建議

- **分頁切換**：Vanilla JS + URL 參數（`?view=repos` / `?view=starred`）
- **摺疊狀態**：localStorage + CSS `display: none` / `display: block`
- **篩選邏輯**：JavaScript 陣列 `.filter()` + `.map()` 渲染
- **樣式框架**：Tailwind CSS（CDN 引入，無需構建）
